# 同一 WorkItem 后续迭代

同一能力保持原 slug。当前轮未验收时继续当前活动；已完成后出现新增范围，运行 `item next-iteration <slug> --state-revision <stateRevision>`。

脚本先归档文档与状态快照，再切换当前轮。历史证据留在不可变存储，由归档引用；不复制整个证据库。归档不自动部署、提交或改变业务代码。

顶层需求与设计维护完整当前规格，计划只写本轮任务。同 WorkItem 的 T 编号持续递增，例如上轮 T01–T06，本轮从 T07 开始；不能复用旧编号。当前任务集合和整体验证重新登记，旧证据不能解锁新任务。

R/D 编号继续引用同一权威定义；新增使用新编号，删除保留停用说明。新轮按风险审阅，日常只读顶层内容，追溯时再读 history/。Workflow Run 自动绑定本轮，不复用旧轮执行状态。
